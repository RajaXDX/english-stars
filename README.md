# نجوم الإنجليزي ⭐

تطبيق ويب لتعلّم الإنجليزي وفق المنهج السعودي، من الصف الأول الابتدائي إلى الثالث الثانوي:
كلمات كل وحدة بالصوت والصورة، شرح القاعدة، وألعاب لجمع النجوم.

## المزايا

- **مسار واضح لكل وحدة**: الكلمات ← بطاقات الحفظ ← تحدي الكلمات ← لعبة التوصيل ← التهجئة ← القاعدة ← تحدي القواعد.
- **زر «كمّل من حيث توقفت»** يفتح الخطوة التالية مباشرة.
- **هدف يومي وأيام متتالية 🔥** ونقاط وأوسمة للتشجيع.
- **كلماتي الصعبة**: الكلمة التي تخطئ فيها تُحفظ للمراجعة، وتختفي بعد إجابتين صحيحتين.
- **قاموس** للبحث في كل كلمات الصف بالإنجليزي أو العربي.
- **يعمل بدون إنترنت** ويمكن تثبيته على الجوال مثل أي تطبيق (PWA).
- وضع فاتح وداكن، ويدعم الطالب والطالبة، ولوحة المفاتيح على الكمبيوتر.
- التقدّم محفوظ على جهاز الطالب فقط، ولا تُجمع أي بيانات.

## التشغيل

لا يحتاج تثبيت أي شيء. افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً (مطلوب لتجربة العمل بدون إنترنت والتثبيت):

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

| الملف | ماذا يفعل |
| --- | --- |
| `index.html` | هيكل الصفحة وشريط التنقل |
| `css/app.css` | كل التصميم والألوان (الفاتح والداكن) |
| `js/core.js` | بيانات الدروس، حفظ التقدّم، النقاط والأوسمة، الصوت |
| `js/ui.js` | الشاشات: الترحيب، الرئيسية، الوحدة، الكلمات، القاعدة، المراجعة، الإنجازات، حسابي |
| `js/play.js` | الألعاب: تحدي الكلمات، التوصيل، التهجئة، تحدي القواعد، بطاقات الحفظ |
| `js/main.js` | تشغيل التطبيق |
| `data/g1.js … g12.js` | محتوى كل صف (الكلمات والقواعد والأسئلة) |
| `sw.js` و `manifest.webmanifest` | العمل بدون إنترنت والتثبيت كتطبيق |

## إضافة أو تعديل محتوى

كل صف في ملف داخل `data/`. الكلمة تُكتب هكذا: `"الكلمة|المعنى|إيموجي"` (الإيموجي اختياري)،
وسؤال القواعد هكذا: `"جملة فيها ___ فراغ|الإجابة الصحيحة|خطأ 1|خطأ 2"`.

**مهم:** بعد أي تعديل تنشره، غيّر رقم `VERSION` في أول `sw.js` حتى تصل النسخة الجديدة للأجهزة التي حفظت التطبيق.

## تطبيق الآيفون والأندرويد

نفس التطبيق يُغلَّف كتطبيق حقيقي للمتجرين باستخدام [Capacitor](https://capacitorjs.com). الكود واحد:
أي تعديل في `index.html` أو `css/` أو `js/` أو `data/` يظهر في الموقع وفي التطبيقين.

| المجلد | ماذا فيه |
| --- | --- |
| `android/` | مشروع Android Studio |
| `ios/` | مشروع Xcode |
| `resources/` | صورة الأيقونة وشاشة البداية الأصلية |
| `tools/build-web.js` | ينسخ ملفات الموقع إلى `www/` ليحمّلها التطبيق |
| `capacitor.config.json` | اسم التطبيق ومعرّفه (`appId`) |

```bash
npm install
```

```bash
npm run android
```

```bash
npm run ios
```

- `npm run android` يفتح المشروع في Android Studio (يعمل على ويندوز وماك ولينكس).
- `npm run ios` يفتح المشروع في Xcode (يحتاج جهاز ماك).
- بعد أي تعديل في ملفات الموقع شغّل `npm run sync` قبل البناء.
- لتغيير الأيقونة: عدّل الصور في `resources/` ثم `npm run icons`.

**نسخة أندرويد تجريبية بدون تثبيت أي برنامج:** كل `push` يبني ملف APK تلقائياً.
افتح تبويب **Actions** في GitHub ← آخر تشغيل لـ *Build apps* ← **Artifacts** ← `english-stars-android-test`،
ثم انقل الملف `app-debug.apk` إلى جوال أندرويد وثبّته.

**الرفع إلى TestFlight تلقائياً:** ملف `.github/workflows/testflight.yml` يبني تطبيق الآيفون ويوقّعه ويرفعه إلى TestFlight.
يحتاج مرة واحدة إلى أربعة أسرار في إعدادات المستودع (*Settings ← Secrets and variables ← Actions*):
`APPLE_TEAM_ID` و `ASC_KEY_ID` و `ASC_ISSUER_ID` و `ASC_KEY_P8` (الشرح في أول الملف)، وأن يكون التطبيق مُنشأً في App Store Connect بنفس الـ `appId`.
بعدها: تبويب **Actions** ← *TestFlight* ← **Run workflow**. لا تضع المفتاح في أي ملف داخل المستودع.

**قبل النشر في المتاجر:**

1. اختر `appId` نهائياً في `capacitor.config.json` (الحالي `com.englishstars.app`)، لأنه لا يتغير بعد النشر.
   غيّره أيضاً في `android/app/build.gradle` وفي إعدادات المشروع في Xcode.
2. **Google Play:** حساب مطوّر (25 دولاراً مرة واحدة)، ثم من Android Studio: *Build ← Generate Signed App Bundle*.
3. **App Store:** حساب Apple Developer (99 دولاراً سنوياً) وجهاز ماك، ثم من Xcode: *Product ← Archive*.
4. المتجران يطلبان رابط «سياسة خصوصية». التطبيق لا يجمع أي بيانات، فتكفي صفحة قصيرة تقول ذلك.
