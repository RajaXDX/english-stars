# نجوم الإنجليزي (English Stars)

موقع ثابت (HTML/CSS/JS بدون مكتبات) لتعلّم الإنجليزي للصفوف ١–١٢ وفق كتب ١٤٤٨.
ينشر على GitHub Pages؛ أي دفع إلى `main` ينشر الموقع مباشرة.

## النطق (Narration)

### كيف يعمل
| الملف | الدور |
|---|---|
| `js/narration-text.js` | تنظيف النص وتوليد المفتاح واسم الملف وقواعد الكلمات متعددة النطق — نفس الكود في المتصفح وفي Node |
| `audio/manifest.js` | فهرس مولَّد: `NARRATION_AUDIO.clips[key] = id` أو `[idM, idF]` |
| `audio/m/*.mp3`, `audio/f/*.mp3` | التسجيلات المولَّدة مسبقاً (صوت ذكر للأولاد، أنثى للبنات، والآخر احتياطي) |
| `audio/voices.json` | وصف الأصوات المستخدمة ومصدرها |
| `js/narration.js` | المشغّل: عنصر `Audio` واحد، وعد ينتهي عند انتهاء المقطع فعلاً، إلغاء آمن |
| `js/core.js` | واجهة `Speech.say(text, slow, meaning)` التي تستخدمها الصفحات |

- **لا يوجد أي طلب لخدمة نطق خارجية أثناء الاستماع.** كل الصوت ملفات ثابتة تُخزَّن للعمل دون اتصال (`sw.js` → كاش `nujoom-audio`).
- **لا مفاتيح سرية في كود المتصفح.** مفتاح ElevenLabs يُقرأ فقط من متغيّر البيئة `ELEVENLABS_API_KEY` وقت التوليد.
- لا تُرفع أوزان أي نموذج للموقع.

### قواعد النص
- `clean()`: يحذف العربي والإيموجي والفراغات `___` والتلميحات بين قوسين إذا كانت عربية أو أرقاماً فقط، ويُبقي علامات الترقيم الإنجليزية.
- `key()`: النص النظيف بأحرف صغيرة بدون علامة النهاية — فـ `Hello!` و`hello` تسجيل واحد (لا تكرار).
- الكلمات متعددة النطق (close, live, wind, read, record, present, minute, tear, lead…) تأخذ مفتاحاً بالمعنى مثل `close::v` / `close::a` حسب المعنى العربي في المنهج، ولكل معنى نطق ARPABET مُراجَع في `scripts/collect-narration.cjs`. الجمل الكاملة لا تحتاج ذلك لأن السياق يحدد النطق.
- `spoken()`: النص المنطوق فعلاً؛ الأسئلة (Wh- أو فعل مساعد + فاعل) تنتهي بـ `?` لتأخذ نغمة السؤال، وعبارات المفردات مثل *Do my homework* لا تُعامل كسؤال.
- اسم الملف: FNV-1a 32-bit مرتين على المفتاح بترميز UTF-8 → 16 خانة hex. أسماء الملفات القديمة ما زالت مقبولة (`legacyId`).

### أدوات المتعلّم
- زر استماع لكل كلمة/جملة، وزر «أبطأ» (نفس التسجيل بسرعة 0.8 مع الحفاظ على طبقة الصوت `preservesPitch`).
- في الملف الشخصي: السرعة الافتراضية (عادية/أبطأ) ومدة الوقفة في «اسمع الدرس» (1/2/3 ثوانٍ) — تُحفظ محلياً.
- «اسمع الدرس» ينتظر نهاية المقطع الفعلية ثم الوقفة، ويُبقي الكلمة مظللة أثناء نطقها.
- يتوقف الصوت عند الضغط على كلمة أخرى، أو تغيير الدرس، أو التنقل، أو إخفاء التبويب، أو زر الإيقاف — بلا استدعاءات متأخرة.
- الاختبارات: في سؤال الاستماع تبقى الخيارات مقفلة حتى ينتهي التشغيل الأول؛ وزر «التالي» ينتظر انتهاء نطق الإجابة.

### البدائل وحدود معروفة
- إن غاب التسجيل أو فشل: يُستخدم **صوت إنجليزي من الجهاز فقط** (لا يُستخدم صوت عربي أبداً)، مع انتظار تحميل الأصوات حتى 1.8 ثانية. إن لم يوجد: رسالة ودّية.
- إن منع المتصفح التشغيل التلقائي: رسالة «اضغط زر الاستماع لتشغيل الصوت.»
- جودة صوت الجهاز تختلف من جهاز لآخر.
- حتى يُعاد التوليد بالنطق المُراجَع، معنيا *close* و*graduate* يشتركان في تسجيل واحد (يظهر تحذير في الفحص).

### الصوت والترخيص
- **الصوت مولَّد بالذكاء الاصطناعي بلهجة أمريكية، وليس تسجيلاً لأشخاص.** هذا مذكور للمستخدم في صفحة الملف الشخصي.
- المرحلي (الحالي): Microsoft Edge neural voices (`en-US-AndrewNeural` ذكر، `en-US-EmmaNeural` أنثى).
- النهائي: ElevenLabs (اشتراك مدفوع؛ الاستخدام التجاري حسب شروط الخطة) — Liam (ذكر) و Sarah (أنثى)، نموذج `eleven_flash_v2` مع وسوم `<phoneme alphabet="cmu-arpabet">` للكلمات متعددة النطق.
- حدّث `audio/voices.json` عند تغيير الأصوات.

### توليد المكتبة (قابل للتكرار)
```sh
node scripts/collect-narration.cjs --stats        # كم عبارة فريدة
node scripts/collect-narration.cjs > entries.json # [{key,text,file,legacy,pos,arpabet,kinds,grades}]
# المولّد (tools/eleven.mjs) لكل مدخل: ينطق entry.text (مع <phoneme> إذا وُجد arpabet)
# ويحفظ في audio/{m,f}/{entry.file}.mp3 — يكتب لملف مؤقت ثم يعيد التسمية، ويتخطى الموجود
node scripts/build-manifest.cjs                  # يبني audio/manifest.js بشكل ذرّي
node scripts/check-narration.cjs --decode         # يفشل عند ملف ناقص/فارغ/لا يُفك ترميزه أو مفتاح مكرر
```
`--decode` يحتاج `ffprobe` (FFmpeg).
