# نجوم الإنجليزي ⭐

تطبيق ويب لتعلّم الإنجليزي وفق المنهج السعودي، من الصف الأول الابتدائي إلى الثالث الثانوي:
كلمات كل وحدة بالصوت والصورة، شرح القاعدة، وألعاب لجمع النجوم.

## المزايا

- **مسار واضح لكل وحدة**: الكلمات ← بطاقات الحفظ ← تحدي الكلمات ← لعبة التوصيل ← التهجئة ← القاعدة ← تحدي القواعد.
- **زر «كمّل من حيث توقفت»** يفتح الخطوة التالية مباشرة.
- **هدف يومي وأيام متتالية 🔥** ونقاط وأوسمة للتشجيع.
- **كلماتي الصعبة**: الكلمة التي تخطئ فيها تُحفظ للمراجعة، وتختفي بعد إجابتين صحيحتين.
- **قاموس** للبحث في كل كلمات الصف بالإنجليزي أو العربي.
- **يعمل بدون إنترنت** ويمكن تثبيته على الجوال مثل أي تطبيق (PWA).
- وضع فاتح وداكن، ويدعم الطالب والطالبة، ولوحة المفاتيح على الكمبيوتر.
- التقدّم محفوظ على جهاز الطالب فقط، ولا تُجمع أي بيانات.

## التشغيل

لا يحتاج تثبيت أي شيء. افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً (مطلوب لتجربة العمل بدون إنترنت والتثبيت):

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

| الملف | ماذا يفعل |
| --- | --- |
| `index.html` | هيكل الصفحة وشريط التنقل |
| `css/app.css` | كل التصميم والألوان (الفاتح والداكن) |
| `js/core.js` | بيانات الدروس، حفظ التقدّم، النقاط والأوسمة، الصوت |
| `js/ui.js` | الشاشات: الترحيب، الرئيسية، الوحدة، الكلمات، القاعدة، المراجعة، الإنجازات، حسابي |
| `js/play.js` | الألعاب: تحدي الكلمات، التوصيل، التهجئة، تحدي القواعد، بطاقات الحفظ |
| `js/main.js` | تشغيل التطبيق |
| `data/g1.js … g12.js` | محتوى كل صف (الكلمات والقواعد والأسئلة) |
| `sw.js` و `manifest.webmanifest` | العمل بدون إنترنت والتثبيت كتطبيق |

## إضافة أو تعديل محتوى

كل صف في ملف داخل `data/`. الكلمة تُكتب هكذا: `"الكلمة|المعنى|إيموجي"` (الإيموجي اختياري)،
وسؤال القواعد هكذا: `"جملة فيها ___ فراغ|الإجابة الصحيحة|خطأ 1|خطأ 2"`.

**مهم:** بعد أي تعديل تنشره، غيّر رقم `VERSION` في أول `sw.js` حتى تصل النسخة الجديدة للأجهزة التي حفظت التطبيق.
